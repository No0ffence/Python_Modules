# Python Modules

This repository contains my Python projects completed as part of the **42 School curriculum**.

The goal of these projects is to develop a strong understanding of Python and improve my ability to write clean, structured, and maintainable code.

Throughout the modules, I work with different aspects of Python, including:

* Object-Oriented Programming
* Classes, inheritance, and polymorphism
* Abstract classes and interfaces
* Type hints and static type checking
* Generators and iterators
* File handling and error management
* Python standard library
* Design patterns
* Modular project architecture
* Virtual environments and dependency management
* Testing and code quality

The projects are focused not only on making the code work, but also on understanding **why a particular approach is used** and how to structure code properly.

## Technologies

* Python 3
* Git
* Linux
* Poetry / `venv`
* MyPy
